#        pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
#
#   4) FaceNet sin reinstalar numpy (evita el error del adjunto):
#        pip install facenet-pytorch --no-deps
#
#   5) Resto de la API:
#        pip install -r requirements-server.txt
#
# Si el paso 2 falla: usa Python 3.11 o 3.12 x64 para el venv (no 3.13 ni 32 bits).
